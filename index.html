01 / Build with confidence

Governance & assessment

Guidance and tools for thoughtful adoption and review.

Guide

Awesome Copilot Governance

A practical guide to policies, settings, and guardrails for GitHub Copilot. Use it to plan responsible adoption and check how governance controls work.

Guide

Awesome GitHub Governance

A field guide to governing GitHub Enterprise, GitHub Actions, and GitHub Advanced Security. Use it to explore policy choices, ownership, and ways to verify controls.

Assessment tool

GitHub Enterprise Assessment

A local dashboard and command-line tool that combines read-only GitHub evidence with a questionnaire. Use it to identify improvement opportunities and create prioritized reports for human review.

Publication toolkit

Publish Solution

A toolkit that turns a publication request into a risk-based readiness plan for a solution repository. Use it to organize controls and evidence for human review before handing off to a separate deployment process.

02 / Learn by doing

Training & productivity

Resources for building practical skills with Copilot.

Training

GitHub Copilot Professional Productivity Training

A one-hour, VS Code-focused training on using GitHub Copilot for personal and small-team productivity. Use its facilitator guide, demonstration, and learner materials to practice building and reviewing a reporting workflow.
